## 🛠️ Installation & Setup


### Clone repository
```
git clone https://github.com/ifra489/express-routing-api.git
```


### Navigate into project
```
cd express-routing-api
```
### Install dependencies
```
npm install
```
### Run server
```
node appe.js
```
###Server runs on:
```
http://localhost:3000
```
## 📌 API Endpoints

### Users
GET /users  
GET /users/:id  
POST /users  
PUT /users/:id  
DELETE /users/:id  

### Posts
GET /posts  
GET /posts/:id  
POST /posts  
PUT /posts/:id  
DELETE /posts/:id
